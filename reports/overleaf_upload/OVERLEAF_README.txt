Overleaf upload package for Image_projet_money presentation.

Files included:
- slides.tex
- assets/generated/* (all figures used by slides.tex)
- slides.pdf (local XeLaTeX build output)

On Overleaf:
1) Upload this whole folder (or unzip and upload all files).
2) Set compiler to XeLaTeX.
3) Main file: slides.tex.

Local build:
1) cd reports/overleaf_upload
2) xelatex -interaction=nonstopmode -halt-on-error slides.tex
3) xelatex -interaction=nonstopmode -halt-on-error slides.tex
